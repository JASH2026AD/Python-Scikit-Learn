# 🤖 Python Scikit-Learn Programs

A collection of Python programs created to practice and understand **Machine Learning using Scikit-Learn**.

This repository contains beginner-friendly programs covering different machine learning concepts, algorithms, data preprocessing techniques, model training, and evaluation.

## 📌 Topics Covered

- Introduction to Scikit-Learn
- Loading and working with datasets
- Data preprocessing
- Feature selection
- Training and testing data
- Supervised Learning
- Classification
- Regression
- Model prediction
- Model evaluation
- Machine Learning algorithms

## 🛠️ Technologies Used

- Python
- Scikit-Learn
- NumPy
- Pandas
- Matplotlib
- VS Code

## 📦 Installation

Make sure Python is installed on your system.

Install the required libraries:


pip install scikit-learn numpy pandas matplotlib
